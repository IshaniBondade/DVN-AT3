# Data and AI Disclosure Statement

## 1. Data Source and Limitations

- **Data Source:** Our project uses Epoch AI's *Notable AI Models* dataset, downloaded on **19 October 2026** under the **CC-BY 4.0** licence.
- **Reproducibility:** The original dataset and Python cleaning script are included in our repository so the cleaned data can be created again.
- **Limitations:** Some models do not share their training compute or parameter details. The dataset also does not cover private models, actual model usage or the full year of 2026 (data is available up to 30 September).

## 2. Generative AI Usage

- **Tools Used:** Our group used Claude, Gemini and Grok for coding help, fixing errors and improving documentation.
- **How We Used Them:** They helped with the initial app layout, chart setup, Git issues and writing. The group made its own decisions about the analysis, data cleaning and charts.
- **Checking:** We checked the code and results using Python and manual checks to make sure the numbers shown in the app matched our datasets. More details are in `AI_PROVENANCE.md`.
