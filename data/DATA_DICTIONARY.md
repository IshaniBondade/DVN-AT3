# Data Dictionary

## 1. Source Dataset: `data/raw/notable_ai_models.csv`
* **Source:** Epoch AI — *Data on AI models* (Notable AI Models database)
* **URL:** `https://epoch.ai/data/ai-models`
* **Licence:** Creative Commons Attribution 4.0 International (CC-BY 4.0)
* **Retrieval Date:** 19 October 2026
* **Time Coverage:** 2 July 1950 – 30 September 2026
* **Latest Observation:** `Gemini 4 Argon` (Google DeepMind, published `2026-09-30`)
* **Primary Key:** `Model` (unique model name string)
* **Row Count:** 1,078 notable AI models (47 raw columns)

### Key Raw Columns Used
| Column Name | Data Type | Unit / Format | Description |
| :--- | :--- | :--- | :--- |
| `Model` | String | Text (Primary Key) | Official name of the AI model. |
| `Organization` | String | Comma-separated text | Developing organisation(s) credited with the model. |
| `Publication date` | Date | `YYYY-MM-DD` | Official release or publication date. |
| `Domain` | String | Comma-separated text | Application domain(s) (e.g., `Language`, `Vision`, `Multimodal`, `Robotics`). |
| `Parameters` | Float | Count (parameters) | Total number of trainable model parameters (nullable). |
| `Training compute (FLOP)` | Float | FLOP (floating-point operations) | Estimated pre-training compute in floating-point operations (nullable). |
| `Frontier model` | Boolean / String | `True` / `False` / Blank | Epoch AI's flag indicating whether the model met frontier criteria at release. |
| `Model accessibility` | String | Categorical text | Access tier (e.g., `API access`, `Limited access`, `Open weights`). |
| `Organization categorization` | String | Comma-separated text | Sector classification(s) (e.g., `Industry`, `Academia`). |
| `Country (of organization)` | String | Comma-separated text | Country or countries where the developing organisation(s) are headquartered. |

## 2. Processed Dataset: `data/processed/models_clean.csv`
* **Generated By:** `scripts/make_processed.py` (run from repo root via `python scripts/make_processed.py`)
* **Primary Key:** `model` (1,078 unique rows, 20 columns: main's 15 shared fields plus five Geography fields)
* **Time Coverage:** 1950 – 2026 (Latest observation: `2026-09-30`; 2026 flagged as `partial_year = True`)

### Deterministic Transform Pipeline (`scripts/make_processed.py`)
1. **Column Standardisation & Selection:** Maps raw columns to snake_case (`model`, `pub_date`, `org_raw`, `domain`, `parameters`, `compute_flop`, `frontier`, `accessibility`), parses `pub_date` via `pd.to_datetime(..., errors="coerce")`, and extracts integer `year`.
2. **Multi-Organisation Attribution (`org` & `n_orgs`):** Counts non-empty comma-separated entries in `Organization` (`n_orgs`, which equals `0` when missing) and extracts the first-listed organisation (`first_listed()`) so multi-institution collaborations are not double-counted in share totals. Missing values are filled with `"Unknown"`.
3. **Parent Entity Consolidation (`ALIASES`):** Maps subsidiary and rebranded lab names to their parent organisation (`DeepMind`, `Google DeepMind`, `Google Research`, `Google Brain`, `Google Cloud` $\rightarrow$ `Google`; `Meta AI`, `Facebook`, `Facebook AI Research`, `Facebook AI` $\rightarrow$ `Meta`; `Microsoft Research`, `Microsoft Research Asia` $\rightarrow$ `Microsoft`) so parent concentration shares are not artificially understated.
4. **Sector Harmonisation (`sector`):** Consolidates `Organization categorization` into clean analytical categories (`Industry`, `Academia`, `Industry + Academia`, `Other`, or `Unknown` when missing).
5. **Primary Country Attribution (`country`):** Extracts the first-listed country from `Country (of organization)` and fills missing values with `"Unknown"`.
6. **Completeness, Partial-Year Flags & Sorting (`compute_reported`, `partial_year`):** Creates boolean `compute_reported` (`True` where `compute_flop` is non-null) and `partial_year` (`True` where `year == df["pub_date"].max().year`, i.e. 2026 through 30 Sep), validates row count, primary key uniqueness, date parsing, and frontier counts via `assert` checks, and sorts chronologically by `pub_date` (`kind="stable"`).

## 3. Geography calculations and map assets

Geography uses `country_raw` to retain all affiliations. `src/data.py` normalises country aliases and deduplicates tags before calculating results in memory. See the [Geography README section](../README.md#geography-tab) for shares, periods, filters and accessibility logic.

- `data/geo/country_codes.json`: source country labels mapped to ISO3 codes, keyed by label.
- `data/geo/world.geojson`: static country polygons keyed by `properties.id` (ISO3), with longitude/latitude coordinates in degrees. Source: `@d3-maps/atlas@1.0.0`, MIT licence. Transform: TopoJSON to GeoJSON using `topojson-client 3.1.0`; Antarctica omitted; coordinates rounded to two decimals. Source URL is recorded in `source-metadata.json`. These assets have no observation dates. Singapore and Hong Kong remain in totals without map polygons.

`python -m src.pipeline build` regenerates the processed CSV and refreshes `source-metadata.json` and `validation-report.json` with counts, share checks and file hashes.
